## Regressions and limits

Portable offline contracts reject invalid transfer digests, task/source/path
bindings, symlinks, wrong sizes, changed review hashes or reports, a revise
verdict at final acceptance, image-backend failures, and malformed MCP arguments.
Small and greater-than-3-MB browser fixtures pass; broken interaction, unwanted
reduced-motion animation and external resources fail.

A 112 KB manager packet was reduced to 55 KB by shortening command diagnostics
only. Every task input, dependency, state, candidate, receipt and allowance,
and the original authoritative digest, were preserved. A real manager returned
a checked repair plan in one model response. The original snapshot remains
available; the compact view is explicitly labelled as a presentation.

The published review definition now specifies top-level JSON arrays and gives
precise diagnostics for the observed nested-JSON mistake. Worker and manager
invocations allow up to three existing Ply verification cycles within their
admitted turn/deadline limits. A new offline executable regression ran the real
worker adapter, Agent, Ply, Ask and native Cage: a wrong candidate was rejected,
corrected within the same task, and accepted with both verdicts in replayable
evidence. No second model loop was implemented.

The native creative evaluation ran on macOS, using configured existing Ask and
image credential adapters. A fresh Linux installation, second physical machine,
production public deployment, full WCAG audit, and arbitrary future briefs were
not tested. OAuth support belongs to the existing A2A component; this live page
exercise tested mTLS. Host reads remain unrestricted under the default action
Cage. Operator-selected programs and controller evidence remain trusted.
