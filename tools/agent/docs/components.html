Bench 0.13.0 contract reference

Every guarantee has an owner.

Bench is sixteen narrow components, not one agent-shaped authority blob. Model access, iteration, confinement, approval, effects, evidence, learning, and durability remain separate ordinary programs with inspectable contracts.

16 pinned components18 public commandsphase-scoped compositionversions from the release manifest

How to read the map

A component owns one consequential job.

The system’s strength comes from the seams between programs. A run selects only the filters required by its phase; the released count is compatibility packaging, not runtime ceremony.

ownership

One decision, one owner

Intelligence cannot quietly absorb authority, evidence, or acceptance.

authority

Granted by the caller

Markdown and model output cannot widen the run’s permissions.

evidence

Written outside the worker

The execution does not own the record later used to judge it.

composition

Programs all the way down

Replace a provider, policy, loop, connector, or projection without replacing the control plane.

The released manifest

Sixteen contracts, including both protocol edges.

“Owns” names the narrow capability. “Boundary” names the guarantee it deliberately refuses to fake. “Durable output” shows what another program can inspect.

How the system composes

The operating system supplies the universal joints.

Programs are capabilities; PATH is discovery; streams carry records; files preserve state; exit status is control flow; signals and process groups coordinate execution.

definition

bench · agent · brief

Admit the promise, assemble the home, disclose the relevant procedure.

intelligence

ask · ply

Reason inside an external checked loop and keep the normalized request history.

evidence

context · cite · trail

Retrieve attributed inputs, gate literal citations, query the authoritative archive.

authority

cage · may · action

Confine commands, authorize exact bytes, execute effects outside worker scope.

promotion

hone · draft

Promote only reviewed recovery and falsifiable design into durable procedure.

durability + edges

tend · mcp · oauth

Persist local execution and translate network capabilities into narrow process seams.

No runtime should maximize filter count.A retrieval task may need Context and Cite; a local edit may not. An external effect introduces Action and May; ordinary file work does not. Phase-scoped composition keeps both the authority set and the evidence story small.
