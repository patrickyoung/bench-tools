# Change control and retirement

## Change classes

### Fact correction

Update the authoritative source. Do not encode a changing fact as a permanent
skill lesson or memory entry.

### Work/state correction

Correct the bounded unit of work or checkpoint when the standing obligation and
procedure remain valid. Preserve the failed evidence.

### Procedure change

Use Hone only when a replay-verified run failed and later passed under the same
meaningful check. Prepare exact proposed skill bytes, inspect them, and admit
without another model turn. Add the failure as a regression case.

### Definition change

Prepare one bounded patch to a governed root definition file. Inspect the patch,
bind it to the current definition through May, apply only the identical approved
bytes, then recompile and revalidate.

### Check, connector, policy, identity, or runtime change

Route to the platform steward. These change the judge or authority boundary and
require independent review, full evaluation, versioning, and rollback.

## Regression after change

Run the checks appropriate to every touched layer:

- Agent structure and compiled view;
- Ask/Trail replay integrity;
- Draft mutation suite for verifier changes;
- teaching, regression, adversarial, and external withheld cases;
- source freshness/conflict tests;
- denial, interruption, duplicate, and effect-unknown cases;
- pilot thresholds and authority review.

One passing replay of the corrected case is not a release gate.

## Retirement plan

### Stop intake

- Disable schedules, events, and manual run entry points.
- Prevent new Action proposals and connector work.
- Cancel queued work or request a controlled stop for running supervision.

### Reconcile

- Review pending May decisions.
- Inspect every dispatched, sent, unfinished, or unknown effect.
- Observe external systems before any explicit retry or resolution.

### Revoke

- OAuth profiles and refresh authority;
- MCP/Context/Action connector admissions;
- service identities and resource scopes;
- browser/computer-use sessions;
- shared toolboxes or policy grants created only for this worker.

### Preserve and dispose

- Record final Agent/suite/skill versions and definition digest.
- Record owner, reason, last accepted verdict, unresolved obligations, and
  retention decision.
- Keep required controller receipts and audit evidence.
- Archive or delete sensitive work/state and holdout material under policy.
- Verify backups, copies, and scheduled cloud tasks are included.

### Sign off

The accountable business owner confirms the job no longer accepts work. The
platform steward confirms access and schedules are revoked. The evidence owner
confirms retention and deletion. Retirement is incomplete until all three are
explicit.
