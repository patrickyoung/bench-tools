# Platform operations

## Budgets

Set finite defaults and per-agent maxima for model turns, rejected cycles,
compactions, command time, retained output, total elapsed time, cost, records,
bytes, files, proposals, effects, retries, concurrent work, and supervision.
Expose exhaustion as a terminal reason requiring an owner decision.

## Scheduling and supervision

Keep distinct:

- business cadence and freshness;
- Agent `bin/wake` quiet/wake decision;
- external scheduler invocation;
- Tend crash-durable local process transitions;
- Cowork scheduled task as a fresh cloud session.

Test every scheduled path from a fresh environment. Confirm skill/plugin version,
runtime, Agent home, controller evidence, connections, identity, output
destination, budgets, and notification remain available. Never rely on the
authoring conversation as state.

## Monitoring

Monitor public facts:

- current admitted definition and runtime versions;
- last check and external case verdict;
- terminal status/reason and budget use;
- source freshness and descriptor drift;
- pending May decisions and Action proposals;
- sent/unfinished/unknown effects;
- replay integrity and evidence retention;
- correction, escalation, incident, and unsafe-effect rates.

Do not use model confidence or a polished summary as a health metric.

## Incident response

Provide a tested path to pause intake, preserve evidence, stop or drain Tend
work, reconcile external effects, rotate/revoke credentials, narrow authority,
roll back runtime/definition/skill versions, and notify accountable owners.

## Change management

Pin skills, suite, checks, connectors, and policies. Every update receives
security review, isolated and coexistence skill evaluations, full Agent
regression, explicit rollout, and rollback. Do not let a moving plugin version
silently change production procedure.

## Retirement

Disable schedules/triggers, stop/drain work, reconcile pending and unknown
effects, revoke credentials/identities/connectors/policies, retain required
receipts, dispose of sensitive work/state/holdouts under policy, transfer
remaining obligations, and obtain business/platform/evidence-owner sign-off.
