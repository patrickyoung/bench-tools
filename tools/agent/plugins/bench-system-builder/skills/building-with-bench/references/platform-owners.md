# Bench platform owners

“Use the full platform” means assign every guarantee to an explicit owner. It
does not mean load every component into every model turn.

## Contents

1. Discover and admit
2. Design and procedure
3. Work and confine
4. Read and connect
5. Approve and affect

7. Selection test

## Discover and admit

### Bench

- Owns the conversation-first workbench, visible reviewed outcome contract, and
  lifecycle presentation.
- Use Review mode for work whose obligation must survive the conversation.
- Does not become another model client, tool runtime, evaluator, or memory store.

### Ask

- Owns one model invocation, provider boundary, exact event log, structured
  output, continuation, compaction lineage, and replay integrity.
- Its replay check proves record integrity and ordering, not truth.

## Design and procedure

### Draft

- Owns `DESIGN.md` and the Design → Build → Prove promotion path.
- Requires an executable check before a design is buildable.
- Mutation proves what the check detects; it cannot prove what was never tested.

### Brief

- Owns Agent Skills discovery, linting, selection, and progressive disclosure.
- A procedure shapes work but is never acceptance evidence.

## Work and confine

### Ply

- Owns the checked action loop. It returns verifier rejection evidence until the
  check accepts or a finite bound, error, denial, or interruption stops it.
- The model never owns the verifier.

### Cage

- Owns the current kernel-enforced model-action write and network boundary.
- It is not a complete read, secret, identity, resource, or virtual-machine
  boundary. Status 125 means confinement was not established and work did not
  run.

### Agent

- Compiles and runs the directory-shaped standing worker: governed definition,
  procedures, toolbox, mutable work/state, checks, specialists, and evidence.
- Definition, mutable state, verdict, and controller evidence remain separate.

## Read and connect

### Context

- Normalizes records from one caller-selected source connector with stable refs
  and retrieval provenance.
- Source authority and support for a claim remain business decisions.

### Cite

- Verifies exact Context reference-to-URL identity in Markdown.
- It does not judge whether the evidence supports the claim or whether every
  claim is cited.

### MCP

- Discovers protocol capabilities, binds calls to an expected digest, calls
  tools/resources/prompts without retries, and can serve filters as MCP.
- Exit 75 is unfinished; 125 is effect-unknown. Neither is success.

### OAuth

- Obtains and refreshes one resource-bound credential and passes one
  Authorization header to one exact child through a file descriptor.
- Tokens stay outside argv, environment, Agent homes, logs, and chat.

## Approve and affect

### Action

- Evaluates a typed external-effect proposal through controller policy, invokes
  May when exact human review is required, executes a connector, and retains
  typed receipts.
- It does not make an ambient shell, browser, or connector safe by naming it.

### May

- Binds one human allow/deny decision to one exact action/job request and spends
  a matching grant once.
- It owns the decision, not durable business state or effect reconciliation.

## Operate and improve

### Tend

- Owns crash-durable local process supervision, timers/signals, immutable events,
  retry after observed failure, and explicit resolution of unknown effects.
- Scheduling a process and defining its business cadence remain separate.

### Trail

- Owns read-only search, projection, bounded windows, lineage, and replay checks
  over Ask history.
- It reports recorded history; it does not infer missing lineage or truth.

### Hone

- Owns proposed procedural learning from a replay-verified failed-then-passed
  recovery.
- It never learns from an unverified success, and proposed bytes require review
  before admission.

## Selection test

For each component, write one sentence:

> We need **[component]** because **[specific guarantee]** would otherwise have
> no owner in this phase.

If the sentence names a convenience instead of a guarantee, defer the component.
