# Development guidance

Trait authors, teaches, and evaluates ordinary Bench workers and teams. Hire
owns the creator; Agent owns worker execution; team entries retain their
composition; Hone owns learning from checked recovery evidence. Bundle packages
independent executables and supplies literal argv transport.

- Keep Trait independently buildable, testable, usable, and versioned. Compose
  public commands; do not import sibling code or add a provider client, model
  action loop, scheduler, mandatory service, registry, or worker/trait schema.
- Preserve ACTION [FLAGS] INPUT_DIR NEW_OUTPUT_DIR. A -request override changes
  the admitted request without editing input. Validate roots and selected packet
  files before model work; keep input, output, and private storage disjoint.
- Create and edit author the complete requested capability, including useful
  programs, applications, and specialists. Reuse Hire's existing creator and
  keep capability guidance in embedded procedure files. Do not make users
  author adapters or cases for the default workflow.
- Create/edit continue through fresh evaluation. Missing cases or capability
  assessment use a separate Hire preparation run whose copied expert must
  remain unchanged. Preserve all supplied evaluation bytes and modes.
  CAPABILITIES.md explains methods, checks, programs/apps, specialists,
  dependencies, entry, and handoffs without inventing unavailable capabilities.
- Explicit evaluation/run.json supplies a relative entry, literal argv with
  bounded whole-token path substitutions, and command prerequisites. It supplies
  no permissions. Absence selects Agent. Do not infer a team entry from the
  presence of child definitions, a filename, or prose.
- Direct prior-output inputs reuse the expert and evaluation recipe, never old
  case work or acceptance as fresh evidence. Preserve starting locks as
  provenance; do not attach unchanged locks to edited definition bytes.
- Train defaults to knowledge/private only when train.json is absent. Explicit
  settings remain strict. Generate missing transfer/regression cases and freeze
  the evaluation before teaching. Training changes only nonexecutable Markdown:
  preserve every other path/mode/byte and all executables, including executable
  Markdown. Code, data, checker, and runtime changes belong to edit.
- Recovery uses Hone's eligibility, exact proposal, bounded Ask review, and
  admission. Preserve no-lesson outcomes and stale-byte refusals; never fabricate
  receipts, silently change route, or retry until a proposal is accepted.
- Before evaluation, obtain the bounded Ask review of the exact definition,
  capability assessment, selected entry, and frozen cases. Record approval and
  reason as automated model review, never human approval, permission, or proof
  of safety/quality. Reject missing, invalid, negative, or stale decisions.
- Agent cases use fresh work and -B. Controller entries run through Record.
  Caller option -entry-boundary host|cage defaults to host for existing team
  compatibility. Source metadata cannot choose it. Host mode has ordinary host
  authority; source review and postchecks do not supply confinement or prevent
  deliberate evidence alteration/change-and-restore races.
- Optional controller Cage uses -net and only fresh work, state, child-evidence,
  and private temporary write roots. Trait source, criteria, outer records,
  and snapshots stay outside these grants. A missing or unsupported nested
  boundary fails with 125; never fall back to host execution.
- State both boundaries honestly: full networking and unrestricted host reads,
  including readable credentials. Child Agent action Cage is a default the
  controller can bypass. Child evidence is controller-writable in either mode,
  not independently trusted Trait evidence.
- Snapshot execution work separately before checking, outside controller Cage
  write grants when that option is selected. Host controllers can still tamper
  with snapshots; do not claim separate directories isolate their authority.
  Run the independent case check against that snapshot with no argv, frozen
  TRAIT_CASE_DIR, read-only/network-denied Cage, and private temporary storage.
  Record binds every case file and declared output. Publish the checked bytes,
  not a later reread of mutable work.
- Pin definition, source, and evaluation identities and recheck after children.
  Stop with 125 on drift. Hashes and source review do not establish semantics.
  Generated criteria are not independently labeled domain truth; visible cases
  are not hidden tests. Acceptance proves only what the selected checks cover.
- Retained-on-cases requires accepted fresh transfer/regression work, not a
  structural check, skill listing, or prose. Do not claim causal skill use or
  improvement over an unmeasured baseline. No model-weight training or automatic
  shared-library promotion occurs.
- Preserve configured provider wrappers and existing program selectors. Missing
  dependencies fail explicitly; do not install software, change credentials, or
  replace existing public controllers with a new runtime.
- Stdout is final result JSON; subprocess streams are retained separately and
  progress goes to stderr. Preserve unfinished, declined, waiting, uncertain,
  and interrupted statuses. Local per-process timeout is 124. Never retry
  automatically or erase unsuccessful attempts.
- Test with fake commands and loopback models, never user credentials. Run
  go test ./..., go test -race ./..., and go vet ./..., plus executable
  integrations for affected public contracts. Report live semantic/retention
  evidence separately from process and packaging checks.

- Cases default to successful exit0. Explicit expected_exit2 permits a checked
  refusal, with optional empty outputs. Matching exit status alone never accepts:
  the independent check must validate the concrete refusal and retained evidence.
  Bind observed status in an external execution.json Record input. Preserve
  actual worker/entry status even when case checking accepts an expected refusal.
  Unknown, interrupted and infrastructure outcomes cannot be expected successes.
