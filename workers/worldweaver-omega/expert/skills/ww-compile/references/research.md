# Supplied Hire knowledge, checked 2026-09-19

These are the supplied research claims, not independently reproduced results,
not Hone recoveries and not browser performance evidence. Source baseline:
Bench 2ec79db01ed479dd1f639e1d6784645cc29071a0. No Bench code changes required.

R1 OpenAI latest-model guidance, retrieved 2026-09-19:
https://developers.openai.com/api/docs/guides/latest-model
Clear autonomy, conflict resolution and calibrated verification. Proposed
adaptation: explicit artifacts, routed skills, recorded use, bounded repairs.
Retain selected gpt-6-astra; persona length is not a performance claim.

R2 SceneGenAgent, ACL 2025 July:
https://aclanthology.org/2025.acl-long.873/
Structured calculable layouts, verification/refinement for industrial scenes.
Proposed adaptation: typed units/constraints, feature pointers, AABB correction
before art. Industrial results do not prove open-world correctness.

R3 LLM-Driven 3D Scene Generation of Agricultural Simulation Environments,
submitted 2026-02-12, authors state IEEE CAI 2026 acceptance:
https://arxiv.org/abs/2602.11706
Domain rules, modular stages and semantic evaluation in Unreal; real-time is
future work. Proposed adaptation: staged intent/biome/runtime/check, contrasting
themes; no copied multi-agent topology or 90 FPS inference.

R4 Procedural Scene Programs for Open-Universe Scene Generation: LLM-Free Error
Correction via Program Search, 2025-10-17, SIGGRAPH Asia per authors:
https://arxiv.org/abs/2510.16147
Relational placement and algorithmic correction preserving layout. Proposed
adaptation: deterministic support/clearance repairs logged before semantic edits.
No transferred perceptual preference rates.

R5 Three.js WebGPURenderer guide, retrieved 2026-09-19:
https://threejs.org/manual/pages/webgpurenderer
https://threejs.org/docs/pages/WebGPURenderer.html
Async init, WebGL2 fallback; WebGPU is experimental and not necessarily faster.
ShaderMaterial/onBeforeCompile/EffectComposer are not that pipeline. Proposed
adaptation: declared renderer tier, compatible nodes or WebGL passes, real tests.

R6 TSL/current examples and BufferGeometry:
https://github.com/mrdoob/three.js/wiki/Three.js-Shading-Language
https://threejs.org/examples/webgpu_tsl_procedural_terrain
https://threejs.org/examples/webgpu_compute_geometry
https://threejs.org/docs/pages/BufferGeometry.html
TSL JS shader vocabulary; indirect draw requires actual WebGPU backend.
Proposed adaptation: optional compute tier, no per-frame GPU readback, worker
CPU navigation/optional-edit path. Inspect installed exports for exact selected version.

R7 https://threejs.org/docs/pages/InstancedMesh.html
Instance update flags, recomputed bounds and disposal remain necessary.
Proposed adaptation: shared resource ownership, global ID lookup independent
of instance order, measured draws, chunk eviction. Instancing isn't a cap.

R8 Infinigen configuration, retrieved 2026-09-19:
https://infinigen.cs.princeton.edu/docs/latest/ConfiguringInfinigen.html
Coarse layout then population, habitats/seeds/distances/detail. Offline Blender
scope. Proposed adaptation: macro/meso/micro, bounded near detail; no runtime claim.

R9 https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Transferable_objects
ArrayBuffer ownership moves and source detaches. Proposed adaptation: explicit
reserved/live byte ledger and stale ticket rejection; worker transfer test.

R10 https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria
https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API
https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB
For requested editing only: quota/eviction/failed transactions limit durability.
Proposed adaptation: paged
sparse chunk deltas, commit feedback, backups, namespace and multi-tab conflicts,
real reload and failure tests. Never promise infinite durable browser storage.

Also https://threejs.org/docs/pages/RenderPixelatedPass.html: WebGL post-processing
only with its compatible renderer; effects need pixel inspection.
Methods A-H from the supplied teaching brief are implemented in compile
(traceability/layout), runtime (vertical slice/determinism/storage/caps),
verify (pixels/performance/fresh matrix) and repair (bounded observed recovery).
All remain engineering proposals until fresh Agent outcomes are evaluated.
