# Publication specialist contract

Inputs: request.json and all explicitly selected regular inputs/ files. Read inputs/source.json for authoritative facts; additional story/design files are selected by the controller. No prior-run discovery.

Output output/spec.json has exactly schema,role,request_sha256,inputs,content. schema is bench.publication-spec/v1. role is presentation-designer. Bind SHA256 of exact request bytes; inputs is a path-sorted list of {path,sha256} for every regular selected input recursively, paths beginning inputs/. No symlinks, duplicate JSON keys or nonfinite values.

content has title and slides (7-12). Every slide is exactly {kind,title,lead,body,fact_ids,message_ids,notes}. kind is cover, message, score_chart, comparison_table, tradeoff, decision or effect_plot. An effect_plot has the additional required comparison_id field, selecting an actual inferential comparison from source.statistics. Its body totals at most 35 words. The controller draws a native editable vector interval plot with mean, marginal confidence interval, unit scale, sample size, Holm p-value, zero and any designer-specified practical threshold. These are editable PowerPoint shapes, not a native chart object; source values and SVG masters remain available. Include effect_plot when a material inference/practical-benefit argument needs it, and keep the required native score_chart and comparison_table. First is cover; include score_chart, comparison_table and decision. title <=90 characters; lead <=210; body is 0-4 short strings totaling at most75 words; score_chart sidebar body is at most28 words. Name each option next to its numbers rather than relying on visual order or respectively. Label criterion scores (for example score 4/5) separately from observed counts (for example 4 of 4 integrations); notes <=1800characters. Cover every required story message. Charts and tables use exact source.json values automatically. tools/render creates editable native PPTX, PDF and slide previews. Vary composition to serve the narrative. Notes explain evidence and support the presenter, preserving caveats visibly when material.

Cover body totals at most 40 words and is visibly emitted. A comparison_table may add table_view: totals (default) or criteria. Use criteria to explain the score drivers: the controller renders criterion, weight, candidate score /5 and weighted points, plus a signed first-minus-second contribution for two candidates. It paginates at three criteria and four candidates per page. Do not promise criterion contributions on a totals table. Notes are presenter support, not a substitute for material visible content.

Compute hashes only after final input selection. Run this definition’s absolute bin/check from the workspace. When request.production=controller, author the complete spec and finish after the authoring check; the trusted host renders and runs full validation. Otherwise the selected host invokes tools/render before the full check. The renderer reads declarative spec only. Source helpers and dependencies are host-controlled. A passed file check establishes structure and binding, not quality. An independent review covers every format and actual rendered previews before release.
