# Publication specialist contract

Inputs: request.json and all explicitly selected regular inputs/ files. Read inputs/source.json for authoritative facts; additional story/design files are selected by the controller. No prior-run discovery.

Output output/spec.json has exactly schema,role,request_sha256,inputs,content. schema is bench.publication-spec/v1. role is editorial-director. Bind SHA256 of exact request bytes; inputs is a path-sorted list of {path,sha256} for every regular selected input recursively, paths beginning inputs/. No symlinks, duplicate JSON keys or nonfinite values.

content has title, subtitle, audience, thesis (strings); messages (3-7 records: id,text,qualification,fact_ids); required_message_ids (2-7 IDs); terminology (string list); report_arc (5-9 headings); deck_arc (7-12 slide topics); design {direction,font,ink,accent,secondary,paper}. Colors are #RRGGBB. Font: Arial, Helvetica or Liberation Sans. Every message cites supplied source.facts IDs and states its material qualification.

content also requires status_label (at most 120 characters) and eligibility_labels (an object mapping every supplied candidate ID to a label of at most 90 characters). These are audience-facing copy, emitted consistently in the workbook, report and deck; never put editing instructions or raw message IDs in them. Qualify a conditional status with its actual permitted scope, such as diligence-only or shortlist-only, and avoid implying purchase approval. Gate labels must preserve the exact checked assessment and its evidence basis: distinguish documentary assertions from independently verified facts, and eligibility with no approved gates from passing a verified test. Never add or remove a gate, claim completed verification, or alter the PM decision. Surrounding prose retains fuller conditions.

Plan for the available production formats. The workbook has Overview, Matrix, Evidence, Scoring basis and Weight scenarios sheets. Complete statistical profiles/tests remain in statistics.json; gate records and complete evidence remain in comparison-data.json/source-notes.json, with selected results interpreted in the report and native presentation evidence. Do not promise additional worksheets, encodings or native capabilities without a controller extension. These audit files are required publications, not omitted data. Separate audience-facing copy from production instructions. The controller checks actual artifacts, values, native structure and every rendered view before the independent publication verdict.

Compute hashes only after final input selection. Run this definition’s absolute bin/check from the workspace. Production roles first invoke this definition’s tools/render; it reads declarative spec only. Source helpers and dependency runtime are host-controlled. A passed file check establishes structure and binding, not quality. An independent publication review covers every format and actual rendered previews before release.
