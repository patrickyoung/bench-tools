# Practice provenance

Operator-researched primary references, accessed 2026-09-13. These notes guide
modern practice; access date is not publication date and inclusion does not
claim a run browsed or verified a source.

- AWS, Application portfolio management (maintained guidance):
  https://docs.aws.amazon.com/whitepapers/latest/aws-caf-governance-perspective/application-portfolio-management.html
  — capability-linked inventories, accountable owners, dependency/cost evidence
  and recurring portfolio assessment. Use these general practices without
  assuming AWS migration is the company's objective.
- UK Government, Technology Code of Practice (updated 2025-07-07):
  https://www.gov.uk/guidance/the-technology-code-of-practice — user needs,
  reuse, interoperability and commercial lifecycle considerations. Government
  approval requirements apply in their own context, not automatically to callers.

- DORA, “Loosely coupled teams” and “Continuous delivery”:
  https://dora.dev/capabilities/loosely-coupled-teams/ and
  https://dora.dev/capabilities/continuous-delivery/ — delivery performance,
  team independence, testability, deployment and feedback; pages are undated
  here.
- FinOps Foundation, “2026 FinOps Framework,” “Unit Economics,” and
  “Allocation”: https://www.finops.org/insights/2026-finops-framework/,
  https://www.finops.org/framework/capabilities/unit-economics/, and
  https://www.finops.org/framework/capabilities/allocation/ — attribution,
  shared cost, accountability and business-value units; no page publication
  date is asserted here.
- NIST SP 800-207, *Zero Trust Architecture* (2020):
  https://csrc.nist.gov/pubs/sp/800/207/final — resource-centric access,
  explicit authentication/authorization and policy enforcement.
- NIST SP 800-207A, *A Zero Trust Architecture Model for Access Control in
  Cloud-Native Applications in Multi-Location Environments* (2023):
  https://csrc.nist.gov/pubs/sp/800/207/a/final — identity-tier and
  application/service policy across locations.
- NIST, AI RMF Playbook:
  https://www.nist.gov/itl/ai-risk-management-framework/nist-ai-rmf-playbook —
  voluntary Govern/Map/Measure/Manage actions; maintained resource, so no single
  page publication date is asserted here.
- CNCF, cloud-native definition:
  https://github.com/cncf/toc/blob/main/DEFINITION.md — resilient, manageable,
  observable, loosely coupled systems; a maintained document, not a fashion
  mandate.
- Martin Fowler, “Data Mesh Principles and Logical Architecture” (2020-12-03):
  https://martinfowler.com/articles/data-mesh-principles.html — domain data
  ownership, data as a product, self-service platform and federated governance.
- Backstage software catalog descriptor format:
  https://backstage.io/docs/features/software-catalog/descriptor-format/ —
  machine-readable entity metadata for an existing catalog; maintained
  documentation with no publication date asserted here.
- OpenAPI Specification 3.2.1 (2026-09-10):
  https://spec.openapis.org/oas/v3.2.1.html — API contract description. Select
  consumer-supported versions; the latest text does not imply old tools support
  it or that automatic upgrades are appropriate.
- Open Policy Agent, policy testing:
  https://www.openpolicyagent.org/docs/policy-testing — testable policy behavior
  and pass/fail evidence; maintained documentation with no publication date
  asserted here.
