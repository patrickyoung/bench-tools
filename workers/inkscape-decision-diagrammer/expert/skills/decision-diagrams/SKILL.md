# Decision framework craft
Read `references/frameworks.md` before selecting/placing. Read
`references/operator-specification.md` for the full approved visual discipline.
The library covers all 17 rows, not just the selector's four. These are grammar
and evidence rules, not code templates. Author per-job stdlib geometry.

Resolve decision, frame, axes/regions, evidenced items, audience/medium first.
Do not invent weights, measured coordinates, owners or dates. Qualitative
positions are layout proposals, not observations. Missing classification uses
a labeled tray; missing data essential to the decision may require needs-input.

Work in three passes: topology and literal content; scalable readable layout;
then restrained craft. Compute cell centers, rank positions, bubble areas,
tree topology and label allocation. All quantitative scales state units and
thresholds; all non-quantitative placement explicitly says qualitative.
Use native text queries to correct allocation, never smaller type as a density
escape. Preserve source IDs across revisions and record omitted membership.

Review hierarchy at thumbnail; then truth, grammar, collisions, consistency,
grayscale/deuteranopia and framing. The external checker establishes only
mechanical facts. Do not claim image viewing from a bounds query.
