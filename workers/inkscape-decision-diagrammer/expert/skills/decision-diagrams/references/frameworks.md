# Framework library and evidence discipline
The range is the useful upper-density target; the larger endpoint is the hard
ceiling. Below-target counts are fine. Ceiling enforcement counts displayed
items/rows, not filler. Clusters need source IDs and a reason; omitted items
need membership and reasons in notes/plan. No framework licenses invented data.

| Framework (plan spelling) | Exact grammar, direction, meaning and action | Ceiling |
|---|---|---|
| Wardley Mapping | Y visibility to user increases upward; user need at top. X market evolution left→right Genesis, Custom-built, Product (+rental), Commodity (+utility), not age/build-buy. Place by maturity evidence. This user's current dependencies point downward; arrow source depends on target. Dashed evolution/proposal separate. Unknown maturity unplaced; preserve high/medium/low visibility bands. | 20–25 nodes; ≤4 chain depths |
| SWOT Analysis | 2×2: X helpful left, harmful right; Y internal top, external bottom. Strengths upper-left, Weaknesses upper-right, Opportunities lower-left, Threats lower-right. Short fact-traceable noun phrases. No automatic choice: next action evaluates how strengths address threats/opportunities. | 4–6 per cell |
| Eisenhower Matrix | Importance increases upward; urgency increases rightward. High/high Do; high importance/low urgency Schedule; low importance/high urgency Delegate (capacity/authority permitting); low/low Delete or Eliminate/Defer. Action verb per item; retain selector's literal action labels. | 5–7 per cell |
| Impact–effort | Y impact low→high upward; X effort low→high rightward; labeled scatter points. Quick wins upper-left, major projects upper-right, fill-ins lower-left, reconsider lower-right. State thresholds, don't stuff quadrants. Optional area for supplied cost/confidence, units/key required. | 12–15 points |
| Risk heatmap | 5×5: likelihood increases upward, consequence increases rightward. Define the five ordered levels of each and cell tolerance accept/mitigate/escalate from supplied policy or explicit proposal. Each risk in exactly one cell. No implied multiplication of ordinal scales unless explicitly justified. | 12–18 risks |
| Power–interest grid | Y power increases upward; X interest rightward. High/high Manage closely; high power/low interest Keep satisfied; low power/high interest Keep informed; low/low Monitor. Name plus role, evidence for placement, no invented stakeholder influence. | 12–16 stakeholders |
| BCG growth–share | Y market growth high at top; X relative share HIGH LEFT, low right. Stars upper-left; Cash cows lower-left; Question marks upper-right; Dogs lower-right. Circle AREA proportional to revenue (πr²=k×revenue), never diameter. State growth/share thresholds, denominator (e.g. largest competitor), revenue unit. Categories are diagnostic, not automatic invest/divest mandates. | 8–12 units |
| Kano | X fulfilment low left/high right; Y satisfaction dissatisfied below/satisfied above. Must-be curve rises then plateaus near neutral, performance rising relation, attractive curve neutral then rising strongly. Attach features to a curve; classification is hypothesis unless customer evidence supplied. Action: test expectations, not rank invented satisfaction scores. | 10–14 features |
| MoSCoW | Four ranked bands: Must (smallest usable scope), Should (important but viable workaround), Could (desirable), Won't this time (explicitly deferred, not “never”). Show count and supplied effort totals per band + overall. Protect Must scope; do not confuse “Won't” with backlog deletion. | 6–10 per band |
| Force-field | Desired change at center line; driving forces left push toward it, restraining forces right oppose. Supplied weight encodes arrow length OR width with declared linear scale. Separate sides, don't imply invented precision; action strengthens drivers/removes restraints. | 5–7 per side |
| Decision tree | Left→right branching. Decision square, chance circle, terminal distinct end shape. Supplied probabilities sum to 1 at EACH chance node; EV=Σp×child value recursively, with units/cost conventions. Decisions are choices, not probabilities; show policy rationale separately. Never normalize conflicting inputs. | depth 4; 16 leaves |
| Options × criteria | Options columns (≤5), criteria rows (≤8). Weights visible and evidence-based, scoring key/range visible; each weighted contribution w×s and separate total row Σw×s. Explain direction (“larger better”) and any supplied normalization. Do not make up weights or hide ties/sensitivity. | 5 options × 8 criteria |
| RACI / DACI | Roles columns; activities/decisions rows. RACI Responsible, Accountable, Consulted, Informed. DACI Driver, Approver, Contributors, Informed. Exactly ONE A in each row, including DACI. Multiple/absent A is a finding requiring resolution, never fixed by changing a person. | 10–12 rows |
| Cynefin Framework | Qualitative soft/curved boundaries: Complex upper-left (emergent causal patterns/enabling constraints, probe-sense-respond); Complicated upper-right (expert-analysis causality/governing constraints, sense-analyze-respond); Clear lower-right (evident cause/effect/fixed constraints, sense-categorize-respond); Chaotic lower-left (no effective constraints, act-sense-respond). Central Confused/Disorder: partition/diagnose unresolved situation. No numeric axes or rigid grid. | 3–5 per domain |
| Now / Next / Later | Three left→right horizons, not false calendar dates. Now committed/current, Next conditional upcoming, Later exploratory. Confidence decreases rightward using labeled neutral tone, not invented probabilities. Record triggers for moving horizons. | 6–8 per column |
| Porter five forces | Rivalry center; buyers, suppliers, substitutes, entrants surround. Each force has a strength verdict + supporting fact. No Cartesian numeric axes or invented causal links. Action identifies competitive pressures to investigate, not generic attractiveness score. | 3–4 facts per force |
| Pre-mortem / fishbone | Spine runs to stated future failure (title); ribs are cause classes, causes branch into class. Organizes POSSIBLE causes, not causal proof. Action tests and mitigates hypotheses. | 5 classes × 4 causes |

## Placement fidelity beyond arithmetic
Preserve all empty semantic regions. The tray is outside classified regions,
clearly titled “Unplaced / evidence needed”; it is not a fifth SWOT category or
a fifth market maturity. Wardley anchors can have unspecified maturity without
asserting uncertainty about their existence. Unknown visibility stays unknown.
A dependency cycle or hard visibility order incompatible with downward links
requires a report, not reversal. Chain depth counts nodes on the longest path.

Cynefin central confusion is a domain of unresolved diagnosis; it is not a
neutral score. Show labels/responses along soft divisions, not crosshair axes.
Porter arrangement does not rank the surrounding forces. Kano curve placement
must be literal and traceable, with text distinguishing hypotheses from evidence.
Risk thresholds, BCG categories and matrix totals do not certify the conclusion.
If the evidence cannot support the supplied verdict, retain the content and pose
the next decision instead of falsely endorsing it.
