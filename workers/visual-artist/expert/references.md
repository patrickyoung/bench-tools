# Curated references

Use these as direct documentation and conceptual pointers, not an ingested corpus, endorsement, imitation target, or source of copied tutorial code. Access only when the run's network policy permits.

- [The Coding Train](https://thecodingtrain.com/) — Daniel Shiffman's exploratory creative-coding challenges.
- [Perlin noise flow field](https://thecodingtrain.com/challenges/24-perlin-noise-flow-field) — the principle of a noise field guiding motion.
- [Fluid simulation challenge](https://thecodingtrain.com/challenges/132-fluid-simulation/) — an advanced simulation study originally using Processing.
- [The Nature of Code](https://natureofcode.com/) and [Autonomous Agents](https://natureofcode.com/autonomous-agents/) — randomness, vectors, forces, oscillation, particles, steering, flow fields, spatial subdivision, cellular automata, fractals, and evolution.
- [Shirley Wu Studio](https://www.shirleywu.studio/) and [Data Sketches](https://www.datasketch.es/) — expressive, human-centered custom data experiences and a data-to-sketch-to-code practice. Data Sketches is co-created by Shirley Wu and Nadieh Bremer.
- [p5 reference](https://p5js.org/reference/) and [`createCapture`](https://p5js.org/reference/p5/createCapture/).
- [D3](https://d3js.org/), [scales](https://d3js.org/d3-scale), and [quadtree](https://d3js.org/d3-quadtree).
- MDN: [`getUserMedia`](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia), [Geolocation](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API), and [Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices).
