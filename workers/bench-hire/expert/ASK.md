# Ask: advisory field note

Reviewed 2026-09-26 against selected Bench HEAD `878780e5878314aec88024bb30f05590eecd50ef`: `tools/ask/README.md` and `tools/ask/ask.1`. For exact current flags, attachment/provider support and limits, consult the manual in the caller-selected checkout; these notes are not a substitute for it. Answer the user's specific Ask question, not the whole manual. In this UI turn, explain and propose only: never invoke Ask, inspect credential stores or turn an Ask suggestion into a bench-hire action.

**Which tool?** Ask is a one-response Unix model client, not a shell, browser, file reader or worker runner. A simple explanation or summary needs Ask alone; Ply adds action/check turns, Agent supplies a reusable expert, Hire authors one. The instruction is argv; data is stdin or actual bytes supplied with `-a`. `ask 'Summarize this' < report.txt` supplies text; `ask -a chart.png 'Describe this chart'` attaches bytes. `ask 'Summarize report.txt'` does **not** read that file. stdout is the answer; stderr holds diagnostics. `-q` suppresses progress, not errors. Commands returned by Ask are suggestions to the caller, never bench-hire actions.

**Model and account.** Choose a provider/model with `-m` or `ASK_MODEL`, using the existing configured account/wrapper. Ask has no login command, token store or refresh loop. `openai-codex` needs an inherited authorization header via `-header-fd`; an externally configured OAuth profile can supply it, e.g. `oauth with PROFILE -- ask -header-fd 3 -m openai-codex/MODEL 'Explain this'` (PROFILE and MODEL are placeholders, not discovered configuration). If a supplied error says the header is missing, inspect the selected wrapper/descriptor handoff, not the user's home or auth store: it does not prove a Mac OAuth login is absent. Agent selects its Ask executable via `AGENT_ASK`; do not replace a configured wrapper with a raw binary. Never ask for, read, expose or invent credentials or profile names.

**Session control.** Plain `ask` starts fresh; `-c` continues current; `-f FILE` creates or continues only FILE and leaves current unchanged. For a separate job, use an explicit session, e.g. `ask -f review.jsonl 'Summarize' < patch.diff` followed by `ask -f review.jsonl 'List risks'`: this avoids accidental cross-job history. Sessions are private append-only JSONL with one writer; `ASK_DIR` selects the archive root. `ask init -f review.jsonl` creates a session without a model call. `ask append -s reviewer -f review.jsonl 'Observed: tests passed'` records an attributed user observation the next model request sees. `ask note -s reviewer -f review.jsonl 'Review complete'` records evidence *outside* model context. `ask replay -check review.jsonl` verifies recorded consistency, not factual truth or permission to repeat an uncertain effect.

**Structured results and failure.** `-schema` sends provider-native schema metadata and locally validates final JSON. Unsupported provider/model schema support, invalid/incomplete/refused output must fail, not silently become prompt-only schema advice. Check status before consuming output (including redirected files): exit 0 means a completed answer, not truth; exit 1 covers operational, validation and output-budget failures; exit 2 means context overflow, **not authentication**; exit 130 means interrupted. Do not use truncated output as an answer.

**Context.** `ask context` estimates usage, not exact tokenization or model-window discovery. `ask compact -at N review.jsonl` below the explicit threshold returns the same path without a model call; otherwise compaction preserves the original and creates a successor with attributed handoff and a recorded summarizer call. It costs a call and confers no authorization. Preserve unresolved effects; the caller must select the continuation. Media attachment support and exact size limits vary with version/provider: consult the selected current manual rather than guessing.

If the Hire UI has no direct Ask configuration/run action, explain the caller's next step using their existing Ask setup without inventing a button or claiming a call occurred. Worker creation/revision fields may carry necessary task knowledge, never executable commands, auth material or authority flags. Do not create a worker merely to answer an Ask question.
