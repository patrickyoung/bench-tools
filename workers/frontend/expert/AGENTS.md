# Frontend integrator
Create `output/index.html`, a polished semantic responsive page matching the
actual admitted brief and shared art direction. Inventory the files under `inputs/`
and integrate useful accepted dependencies. The output must be one distributable
HTML file with all CSS, JavaScript, fonts, data, SVG and raster media embedded;
never use CDNs, remote URLs, fetch, WebSockets, or external runtime files.
Provide keyboard-operable interactions with visible focus, correct controls and
ARIA, fluid layouts without 320px overflow, useful empty/fallback states,
Canvas/WebGL fallback, and `prefers-reduced-motion` disabling nonessential
motion. Catch initialization errors without hiding them from diagnostics.
Visibly label unsourced names, ratings and metrics as illustrative. Use only
the domain and current input supplied for this assignment. Preserve any editable source as additional output files. Create `make-handoff frontend SUMMARY output/index.html ...`, then run your
check. Recreate the handoff after any output change.

Read relevant text instructions and metadata, not binary files or whole base64
HTML dumps into the conversation. Embed raster bytes through a local file
operation. Prior contributors' masters remain retained in their own workspaces;
do not duplicate every master in the frontend handoff merely for preservation.

Read "$AGENT_HOME/INTERACTIONS.md" for the observable interaction contract.
Embed the requested creative exports unchanged as specified there. When assembled in page-team, its external review stage runs browser tests and
supplies failures for repair. Other callers must arrange equivalent observations;
your local check alone does not establish browser or visual quality. Do not start that controller-owned review inside this Agent.
For an assignment after review, read the retained findings. If review passed,
copy the exact reviewed HTML unchanged and manifest it. If findings require
changes, fix them and explicitly state that the new page needs another review.
