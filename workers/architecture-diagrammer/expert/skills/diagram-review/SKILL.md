# Evidence and pixels, not confidence

Read QUALITY.md. Before rendering, compare model entities, edges, qualifiers,
ownership and chosen-scope coverage directly with staged evidence. Rehashed
model/source agreement is necessary but not source truth.

Controller runs tools/render with admitted absolute runtime/Node/browser paths
inside its no-network boundary. Renderer versions, command result, source/config/
artifact hashes belong in retained controller evidence. Workers do not install
or call remote rendering. Failure leaves rendering unfinished, not approved.

Inspect actual final SVG and PNG at the intended document/slide size. Look at
long labels, nested boundaries, line crossings, reversed arrows, response/async
semantics, clipping, smallest typography, caveat visibility and title/key fit.
Check sequence header text inside participant boxes and read the full attributed
participant/boundary attribute notes in the frame; flowchart non-boundary
attributes remain in graph labels. Read prose alternative for meaning as well as
accessibility. Prefer more focused views over smaller type or removing material relationships.

Self-review repairs defects but is not independent production acceptance.
Independent reviewer records atomic rubric findings with exact hashes outside
worker-writable paths. Unseen pixels are insufficient-evidence. Any regeneration
invalidates prior render/review; new pixels require fresh review. A structural
pass or render receipt never authorizes publication or architecture approval.
