# Create and use Bench workers and teams

Start with [START-HERE.md](START-HERE.md) and the [Bench skill](.agents/skills/bench/SKILL.md).
Follow its Claude Code or Cowork setup reference for the actual execution host.

For a user job, inspect the worker and team catalogs first. Export a suitable
pinned definition or assembly; use Hire for missing expertise or adaptations.
Run an individual worker through Agent or use the team's documented command.
Evaluate the result and leave source identity, output paths and a repeatable
invocation for the next session. Keep job content and development records out
of reusable source. The shared skill contains the detailed procedure.

For requested repository changes, follow [AGENTS.md](AGENTS.md) and the affected
component's guidance. Preserve the independent Unix programs.
